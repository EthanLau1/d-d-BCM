01 / 原创设计与 CC0 声明

7,700 辆机车 NFT 全面采用 CC0 协议

明确原创设计与版权边界：车是我们的原创设计，NFT 整体属于公共领域 (CC0)，瓶盖商标归原品牌方所有。

一辆完整的 BCM 数字机车 = 原创车架与机械设计（我们自主原创） + 瓶盖元素（其他饮品品牌）。

车身与机械结构是我们团队的原创设计：包括 101 个独立车架、机械骨架、轮毂、引擎、把手、避震系统等。BCM 团队历经 3 年时间，以废弃零件手工焊接 101 部实体机车并完成原创数字绘制。这是我们的原创工匠作品，拥有完整自主设计权。

7,700 部数字机车 NFT 全面采用 CC0：正因为车辆机械结构是我们的原创设计，我们主动选择以 CC0 1.0 Universal（放弃版权，进入公共领域） 的方式将 7,700 部数字机车 NFT 奉献给全球社区。任何人都可以自由进行二创、改装、商业化使用或衍生品开发，无需经过团队许可。

瓶盖元素来自其他饮品品牌（版权非 BCM 所有）：机车上的瓶盖图层取自市场上真实存在的饮料品牌 Logo（如可乐、纯水、矿泉水、茶饮、果汁等）。这些 Logo 和标识是各大品牌厂商的注册商标与知识产权，版权不属于 BCM。

⚠️ 艺术二创与非代言声明：BCM 采用波普艺术（Pop Art）拼贴手法向街头改装文化与环保反思致敬。BCM 与任何瓶盖饮料品牌均无商业代言、官方联名或背书合作关系。

04 / 理念

为什么 BCM 存在？

"每一个瓶盖，都值得被重新看见。
不做高高在上的说教，把被遗弃的日常废品，变成帅气热血的艺术品。"

01

废弃物的艺术重生

源于主创在垃圾处理场的震撼：堆积如山、等待填埋或焚烧的废塑料瓶盖，是日常随手丢弃的缩影。BCM 将其清洗、分类，重构为 109 种独特的电单车车轮，让最微小的废弃物重获新生。

02

两个世代的原创执念

20多岁青年设计师的街头美学，碰撞30多岁科技产品人的工程严谨。历时 3 年手工焊接打磨出 101 部原创车身骨架。“把环保与电单车原创设计结合，做真正有意义的产品”是团队唯一的初心。

03

拒绝空谈的真实手作

严格恪守 5R 零废弃原则，所有原料 100% 取自回收废品，绝不采购新塑料。已在广州成功举办多期实体手作工坊，带领上百位参与者亲手把瓶盖变成机车潮玩，让环保成为触手可及的生活方式。

关于 BCM，新用户常问的问题

机车是如何发行的？

智能合约每 24 小时自动生成并释放 1 辆机车进行公开铸造与竞拍。当天竞拍结束后，下一辆机车自动生成并开启新一轮 24 小时释放。
BCM 机车 NFT 的版权 (CC0) 与原创权是如何界定的？
101 款车身与机械结构 100% 属于团队原创设计：团队历时 3 年用废弃金属手工焊接 101 部实体机车骨架。整体 7,700 辆数字机车 NFT 采用 CC0（公共领域）协议，向所有人开放商用与二次创作；轮毂瓶盖上的饮品品牌 Logo 属于对应商标持有人，属于非商业代言性质的当代波普环保致敬。
什么是"死亡螺旋"？BCM 会发生吗？
死亡螺旋（Death Spiral） = GameFi 项目最常见的崩盘模式：新玩家增长停滞 → 奖励代币价格下跌 → 老玩家撤离 → 价格继续跌 → 死亡循环。

经典案例：Axie Infinity 的 SLP 代币从高点跌 99%+。2026 年报告显示 90%+ GameFi 项目已死，$15B 融资中大部分归零。

BCM 为什么不同：
· BCM 暂不发币，没有 Token 价格风险
· BCM 不承诺收益，不靠"投机型玩家"驱动需求
· BCM 作品价值来自设计本身与实体手作积淀，不靠二级市场炒作
BCM 的 7,700 辆机车是如何组成的？
由团队历时 3 年手工焊接打磨的 101 款原创车架，搭配 109 种真实废弃瓶盖转换而来的轮毂元素，加上引擎、车灯、把手等多种可组合配件，在区块链上形成 7,700 辆独一无二、数据不可篡改的链上机车资产。
Gas 费是什么？我要付多少？
Gas 费 = 区块链交易的"手续费"，付给网络矿工/验证者，不是项目方收的。

在 Layer 2 网络上参与时你要付的：仅需极低 Gas 费（~¥1-5）。
我是 Web3 新手，怎么参与？
不需要懂复杂的区块链技术。每日机车释放时，你只需要：
1. 下载一个 Web3 钱包 App（MetaMask / OKX Wallet / Rabby）
2. 准备少量 ETH（几百元即可参与出价或体验）
3. 访问 bcm.motorcycle，连接钱包参与今日机车出价
4. 确认交易后，机车资产直接进入你的个人钱包
